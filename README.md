# rclone nas-backup

Personal branding / privacy pages for the **rclone → Google Drive** OAuth client used to sync household NAS backups (`Z:\\backups` → Drive).

Not a public product — exists so Google Auth Platform Branding has valid homepage + privacy URLs.

## URLs for Google Cloud Branding

| Field | URL |
|-------|-----|
| Application home page | https://ypsilontm.github.io/rclone-nas-backup/ |
| Privacy policy | https://ypsilontm.github.io/rclone-nas-backup/privacy.html |
| Authorised domain | `ypsilontm.github.io` (and/or `github.com`) |

Fallback (also fine on authorised domain `github.com`):

- Homepage: https://github.com/YpsilonTM/rclone-nas-backup
- Privacy: https://github.com/YpsilonTM/rclone-nas-backup/blob/main/privacy.html
